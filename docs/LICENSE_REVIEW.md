# License review — 8 October 2026

This records outstanding provenance questions. It does not change an upstream license or grant permission on an author's behalf.

## Vibrant Teal Dark

Source: https://github.com/aktzx/cinnamon-themes

The README identifies Mint-Y as the base. The upstream repository tree contains no explicit LICENSE/COPYING file. Mint's base copyright notice declares GPL-3.0-or-later and is already included in the bundled theme. The author's modifications still need a clear notice or confirmation; the absence of a file alone does not determine the legal status of a derivative.

Suggested issue text, prepared but not sent:

> Hi! I am creating an open-source desktop appearance manager for Linux Mint 22.3 Cinnamon and would like to include Vibrant-Teal-Dark, with attribution and its editable source. Your README identifies Mint-Y as the base, which is GPL-3.0-or-later. Could you confirm the license covering your modifications and add a license notice to this repository? If GPL-3.0-or-later applies to the complete theme, I will retain the Mint copyright notice, credit your work and include the license text. Thank you!
