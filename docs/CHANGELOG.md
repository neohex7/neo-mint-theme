# Changes

## 1.0.3 — First public beta

- English desktop appearance manager for Linux Mint 22.3 Cinnamon on X11.
- Custom application and desktop themes, green icons, top panel, Plank dock and terminal colors.
- Adjustable display sizes, wallpaper choice, panel/clock settings, dock settings and optional effects.
- Journaled Apply, Undo, Restore Original Appearance and interrupted-operation recovery.
- Correctly initialize the window effect's UPower client to prevent a Cinnamon crash during Restore.
- Move panels before replacing applets, refresh applet settings after loading and preserve existing battery indicators.
- Validate installed file permissions and publish the package with Maintainer set to neo.
- Verified repeated Apply/Restore, dock resize/Undo and persistence after reboot in a Mint 22.3 Cinnamon VM.

Please report bugs and suggest customization improvements through GitHub Issues.
